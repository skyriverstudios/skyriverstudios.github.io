Tables of related enums for use in Zoner. Each enum is a frozen table with both name and value lookups, as well as optional associated properties.

Display name of the item (e.g. "Fast")

Value: number--

Numeric id returned when indexing by name

DetectionMethod​

</>
interface DetectionMethod {
Automatic: EnumItem--

Auto-pick based on container shape & coverage/mode;

Efficient: EnumItem--

Fastest. Uses simple CFrame and Size math checks to determine location in the Zone Volume.

Simple: EnumItem--

Balanced: may use GetPartBoundsInBox/Radius for modest cost and good fidelity.

Complex: EnumItem--

Highest accuracy: per-part or mesh-aware paths like GetPartsInPart; most expensive. If ZoneContainer has no Instances, they will be created.

}

DetectionMode​

</>
interface DetectionMode {
Full: EnumItem--

Target must be fully inside or outside the Zone bounds to trigger entrance or exit.

Touch: EnumItem--

Any intersection with the zone boundary counts (partial overlap). (Doesn't actually use .Touched)

Point: EnumItem--

One or more representative points must be inside (fastest). Often pairs with Efficient math tests.

}

DetectionCoverage​

</>
interface DetectionCoverage {
Center: EnumItem--

Check only the target's center point (very fast). Often math-only.

AllParts: EnumItem--

Every relevant part/point must satisfy DetectionMode (strict).

AnyPart: EnumItem--

At least one relevant part/point must satisfy DetectionMode (lenient).

}

Rate​

</>
interface Rate {
Slow: EnumItem--

Step period ≈ 1.0 s between evaluations.

Moderate: EnumItem--

Step period ≈ 0.5 s.

Fast: EnumItem--

Step period ≈ 0.1 s.

Immediate: EnumItem--

Step period 0 s (continuous / every frame slice).

}

Execution​

</>
interface Execution {
Serial: EnumItem--

Single-threaded group holder. Supports manual stepping via Zone:Step(...) when ManualStepping = true.

Parallel: EnumItem--

Actor-backed parallel evaluation. Manual stepping not exposed; runs on its own schedule. Fastest with lots of Zones.

}

Simulation​

</>
interface Simulation {
PostSimulation: EnumItem--

Run after physics; safe for effects based on final transforms.

PreSimulation: EnumItem--

Run before physics; good for preparing forces/constraints.

PreRender: EnumItem--

Run before rendering (client). On server, requests are coerced to PostSimulation.

}

Bounds​

</>
interface Bounds {
Automatic: EnumItem--

Auto-select bounds model from the container (boxes/spheres vs per-part).

BoxExact: EnumItem--

Automatically creates a Rotated Box (No Instance unless specified) that fits the sum of the ZoneContainer

BoxVoxel: EnumItem--

Automatically creates a Rotated Box (No Instance unless specified) that fits the sum of the ZoneContainer, then rounds to Voxel Grid

PerPart: EnumItem--

Evaluate each contained BasePart or {CFrame, Size} individually as the sum of the whole Zone.

}
